Complete L1/L2 sweep

Fixed hierarchy policies
These semantics are held constant across all 24 structural and capacity combinations.

      

        
Topology
Private L1, shared L2
One L1 per core and one L2 shared by all cores. L2 is consulted only after an L1 miss.

        
Line layout
Fixed 4 × 4 CIN × COUT
tag=(kh,kw,cin//4,cout//4). Each line is 16 bytes at one byte per weight, identical at both levels.

        
Replacement
LRU within each structure
Fully associative, 32-way set associative, and 4-way set associative use true layer-shape radices for set indexing.

        
Miss fill
Inclusive hierarchy
An L2 hit fills the requesting L1. An L2 miss represents an off-chip fetch and fills both L2 and that L1.

        
Concurrency
Tick-atomic L2 snapshot
All same-tick L2 lookups see the start-of-tick state. Fills and hit touches are applied afterward in ascending core order.

        
L2 policy
COUT+1 prefetch and pinning
An L2 miss prefetches the next valid COUT block. Same-tick hits are pinned; overflow falls back to the pre-touch LRU order.
