# Layer shapes of the captured input spike traces

Generated by `catalog_layer_shapes.py` (`conda run -n base .venv/bin/python -I catalog_layer_shapes.py --metadata-only`); do not edit by hand.

## Conventions

- Every trace `.npy` is binary `uint8` with shape `[T, N, Cin, Hin, Win]`, recorded in `meta.json` `layers`. `t` = T, `inc` = Cin, `oc` = `layer_params.cout`, `kh = kw = layer_params.kernel`, `stride = layer_params.stride`.
- **spiking-GEMM** = an `nn.Linear` (or `SpikingGEMM`/`SpikingFC`) target, i.e. a layer listed in `meta.json` `gemm`. Its input `[M, K]` is stored as `Hin = M`, `Win = 1`, `Cin = K`; output features `N = cout`. In this table a GEMM is written as a 1x1, stride-1, unpadded conv: `kh = kw = 1`, `inc = K`, `oc = N`, `ho = M`, `wo = 1`. For transformer layers M is the token count per sample.
- **spiking-Conv** = an `nn.Conv2d` target (not in `gemm`). `ho`/`wo` use the module's real padding and dilation: `ho = (Hin + 2*padding - dilation*(kh-1) - 1) // stride + 1`. Padding, dilation and groups for A02–B09 are module-derived and were not re-verified against the delta metadata, which does not contain these fields. For C01, the captured convolutions use padding 1, dilation 1 and groups 1, checked from the pinned VGG8 constructors without executing them. (The wcache loader `build_workload_from_trace` instead assumes `PAD = 1`, 3x3, stride 1 and skips every other layer via `exclusion_reason`.)
- `#` is the capture order (`layer_NN` prefix), which is the order the layer first fired in the forward pass, i.e. network order.
- Weight-bearing layers whose input was not exactly 0/1 were not captured; they are listed per benchmark under "Not captured" and have no trace, so no shape row.

- Trace directories: all 8 `meta.json` files under `/u/yyu9/projects/neuro_cache_wcache/examples/input_trace/delta`. The tables cover the real n=500 captures.
- From `meta.json`: `arch`, `dataset`, `timestep` (T), `n_samples` (N); `layers[name] = [T, N, Cin, Hin, Win]`; `layer_params[name] = {cout, kernel, stride}`; `gemm[name] = {M, K, N}` (presence marks a GEMM; K = Cin, M = Hin, N = cout, Win = 1); `excluded_layers`. Every trace has N = 500 and subset seed 0.
- These fields are written by `capture_traces.py` (`_capture_workload`, `_stack_layer`, `_module_params`). Layer names are `layer_NN_<sanitized module name>`.
- Conv padding, dilation and groups for A02–B09 are module-derived and were not re-verified against the delta metadata. C01 values were read statically from `VGG8` in `upstream/SMA-AZO/SMA VGG/vgg8_cifar10dvs_SMA.py` and `vgg8_dvs128_SMA.py`: block2–block5 use 3x3 stride-1 padding-1 convolutions with default dilation/groups of 1. Metadata-only mode uses these explicit architecture settings in `CONV_SETTINGS` and rejects unsupported convolution settings. Output spatial dimensions use the formula above.
- The trace format is read by `/u/yyu9/projects/neuro_cache_wcache/src/lays/weight_trace_gen/trace.py` (`load_layer_trace`, `layer_params`).
- Regenerate: `conda run -n base .venv/bin/python -I catalog_layer_shapes.py --metadata-only`. Metadata-only mode reads metadata without importing model loaders or loading models, datasets or checkpoints.
