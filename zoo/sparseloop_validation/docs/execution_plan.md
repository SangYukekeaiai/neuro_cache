## A3. SAF configuration per architecture (boss point 3)

| Arch | Input (spike) operand | Weight operand | SAF |
|---|---|---|---|
| LoAS | SPARSE, bitmask-compressed. Paper (MICRO'24, Sec IV-A): spikes packed across all T timesteps beneath the k dimension, one bitmask per fiber + packed nonzeros; CSR/CSC rejected as too costly for 1-bit values | DENSE - boss decision: input-sparse weight-dense variant, NOT the paper's dual-sparse intersection | leader-follower skipping, input operand leads: weight reads and MACs occur only at input-nonzero positions; no weight-side metadata, no intersection unit |
| PTB | SPARSE, temporal sparsity; HPCA'22 processes "active synaptic inputs" in parallel time-windows (S+partial-T, timesteps sequential inside a window). EXACT input format into the SAF: pending the STSAP section of the PTB paper - open item O1 | DENSE (PTB has no weight-sparsity support, LoAS Table I) | compute gating/skipping driven by input spikes only; weight traffic dense unless O1 says otherwise |

O1 (CLOSED, boss-supplied STSAP passage 2026-11-16): PTB trims silent presynaptic neurons (all-zero TB-tags) without fetching them - neuron-granularity skipping of weight fetches and compute; StSAP packing (greedy 1's-complement pairing of non-bursting neurons, max 2) improves utilization only - it changes latency, not access counts. For the CYCLE comparison PTB's packing must be reflected in the pinned mapping's effective parallelism or stated as unmodeled; S2 decides and records which.

O2 (open): what Sparseloop's actual-data density model takes as input (per-tile occupancy distributions vs raw tensor profiling) - impl investigates during S1 against the installed version; Eyeriss V2 precedent says the mode exists and "accounts for the exact intersections... at the cost of a slower modeling speed".

## Execution and self-checks

Steps run on manager authority (EDP delegation) except the two gates. Each step: inputs -> module -> outputs. All module code new, under `src/`.

1. **S0 Ingest.** Copy the five external snapshot families into `inputs/` with `snapshot_manifest.json` (source path + SHA256 each). Includes the one-time density measurement over the read-only traces (`src/measure_density.py`) and the one-time extraction of Tier C count rows from the fetched campaign archive (`src/extract_real_counts.py`). Self-check: re-hash after copy; manifest is the complete list of external reads.
2. **S1 Install + smoke.** Conda env `tlv` with timeloop + accelergy (pip; source build into `vendor/` as fallback). Run the shipped example once. Output: `outputs/env_manifest.json`. Only step with schedule risk.
3. **S2 SAF mapping writeup + sparse-opt YAMLs.** Inputs: A3 + the two papers. Module: hand-written `configs/sparse_opts/*.yaml` + `docs/saf_mapping.md` quoting the paper passages (LoAS IV-A compression, PTB STSAP) and resolving O1. This is the boss-checkable record of what each SAF models and what it deliberately omits.
4. **S3 Config generators.** `src/make_arch_yaml.py` (inputs/hardware.json -> configs/arch/ + provenance, unmapped rows listed with disposition), `src/make_constraints.py` (inputs/schedule_manifest.json -> per-layer constraint YAML; self-check: constraint x workload reproduces manifest tile sizes), `src/make_workloads.py` (layer_set + densities -> workload YAMLs).
5. **S4 Custom ERT.** `src/make_ert.py`: inputs/energy_table_asap7_syn.json -> `configs/ert/ERT.yaml`. Self-check `outputs/ert_identity_check.csv`: one hand case priced via Accelergy and via a frozen expected-value computed from the snapshot table agrees < 0.1%. This is what reduces energy agreement to counts agreement.
6. **[GATE V]** Boss reviews inputs/snapshot_manifest, saf_mapping.md (O1 resolved), config families, ERT check.
7. **S5 Bernoulli traces.** `src/gen_bernoulli.py` -> `outputs/traces_bernoulli/` (12 layers x 5 p x 3 seeds = 180 single-timestep traces in nocsim input format). Never writes near the read-only trace tree.
8. **S6 nocsim Tier B.** nocsim invoked on S5 traces with arch configs derived from `inputs/hardware.json` -> `outputs/nocsim_counts/tier_b/` (360 cases, per-case fingerprint, idempotent).
9. **S7 Sparseloop runs.** `src/run_timeloop.py` invokes `timeloop-model` per case (Tier B: 120; Tier C: 24) -> `outputs/tl_stats/`; `src/parse_tl_stats.py` -> `outputs/tl_counts.csv`. Idempotent by config SHA.
10. **S8 Join + score.** `src/join_and_score.py`: tl_counts + nocsim_counts/tier_b + inputs/nocsim_counts_real -> `tier_b_error.csv`, `tier_c_gap.csv`, `latency_ratio.csv`, `VALIDATION_SUMMARY.md`. Self-checks: T-divisibility; one documented reconciliation of Timeloop vs nocsim fill/update counting conventions (the classic silent-mismatch source) recorded in the summary before any error number is computed.
11. **S9 Render.** `src/render_figure.py`, the APPROVED mock layout kept as-is (one panel per arch; x = operand density; analytical Sparseloop line, nocsim Bernoulli squares with seed ranges, real-trace triangles at measured per-layer density; MAE/gap annotations) with the y-axis now processing cycles normalized to dense -> `outputs/validation_figure.{pdf,png}`, `caption.txt` (carries: cycles-primary paradigm, actual-data density model, pinned mapping, shared ERT for the supporting energy check, T-scaling, input-sparse weight-dense LoAS variant, GustavSNN exclusion). validation_mock.py gets re-rendered to this layout before GATE V.
12. **[GATE W]** Boss reviews figure + VALIDATION_SUMMARY; paper integration only after sign-off.

Dependencies: S0 -> S1 -> (S2, S3, S4 parallel) -> GATE V -> (S5 -> S6) parallel with S7 -> S8 -> S9 -> GATE W. Tier C needs zero new nocsim compute.

## Caveats

- The ERT carries the fig1 ASAP7 Genus table's caveats verbatim: no post-route parasitics, unconstrained I/O, mixed default library corners (0.77V/0C and 0.70V/25C), linear width/depth interpolation, additive composition; SRAM is FN-CACTI 7nm/0.7V extrapolated; DDR4/IO are commodity models. Nocsim Tier C rows priced under the same table, so the shared-price property still holds.
- Sparseloop's hypergeometric model is exactly the independence assumption Tier C is designed to break; Tier B agreement + Tier C gap together are the claim, neither alone.
- If PTB's spike handling (O1) turns out not to map to any clean Timeloop SAF, PTB's validation reduces to memory-system counts only, with the reduction stated in saf_mapping.md.
